# UB Consultores — Sitio web

Sitio web de una sola página. Todo el contenido (estilos, scripts e imágenes) está incluido en `index.html`.

Para verlo, abre `index.html` en el navegador.

## Diagnóstico de madurez

El test (`#diagnostico`) y el envío del PDF por correo están documentados en [`apps-script/README.md`](apps-script/README.md).
Un PDF de ejemplo, con datos ficticios, está en [`diagnostico/ejemplo/Diagnostico_UB_ejemplo.pdf`](diagnostico/ejemplo/Diagnostico_UB_ejemplo.pdf)
(es una aproximación hecha fuera de Google; el PDF real lo genera `apps-script/Pdf.gs`).
El reporte interno que recibe el equipo de UB tiene su propio ejemplo en [`diagnostico/ejemplo/Reporte_interno_ejemplo.pdf`](diagnostico/ejemplo/Reporte_interno_ejemplo.pdf) (lo genera `apps-script/Reporte.gs`).
